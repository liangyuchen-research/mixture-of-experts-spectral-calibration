# Archived numerical analyses

These CSV files are byte-for-byte copies of the supplied version-6 analysis outputs. They were not regenerated by running a model during repository preparation.

| Folder | Archived content |
| --- | --- |
| `archived_results/model_v6/` | Stage-2 and stage-3 testing/validation concentration readouts and model-error columns |
| `archived_results/matrix_matched/` | Condition-specific calibration curves, strategy summaries, and row-level comparisons |
| `archived_results/per_matrix_r2/` | Per-condition R-squared, slope, standard-deviation and detection-limit tables, plus testing predictions |

The model result tables contain 310 test rows per stage and 8,000 validation rows per stage. The separate matrix-calibration analyses use aggregated `Mean_3.csv` measurements according to the original analysis note; their row counts and protocols are different. Do not combine their metrics as though they came from one evaluation.

The original analysis note says reported numerical values were rounded to three significant figures while condition identifiers and counts were retained. Consequently, `predicted - measured` recomputed from rounded columns may differ slightly from the stored error column. The summary utility uses that stored error column consistently and marks its provenance in the output.

```bash
python scripts/summarize_archived_results.py
```

The missing `matrix_calibration.py` and `calibration_per_matrix.py` were referenced by the original notes but were not supplied. Their algorithmic choices cannot be fully reconstructed from output tables. Archived strategy labels such as `clean-only` and matrix-matched variants are retained as data labels rather than expanded into unsupported methodological claims.
