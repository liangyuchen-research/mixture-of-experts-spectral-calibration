# Measured example tables

`sodium_matrix_calibration.csv` is the complete measured Na-condition mean table, copied without numerical changes from the research archive. It supports the matrix-specific calibration command in the repository README.

`sodium_matrix_mean_spectra.csv` is the earlier compact format example. Its retained rows contain only zero metal concentration and cannot independently establish a calibration curve.
